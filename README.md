# Number Guessing Game

A simple Java console-based Number Guessing Game.

## Features

- Player name input
- Easy, Medium and Hard difficulty levels
- Random secret number between 1 and 100
- Limited attempts based on difficulty
- Too High / Too Low hints
- Game Over message
- Play Again option

## Technologies Used

- Java
- Eclipse IDE
- Git
- GitHub
